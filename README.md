# AI & Blockchain Digest

Weekly digest of notable developments in AI and blockchain, targeted at developers and tech professionals.

## Structure

```
posts/            # Weekly digest posts (YYYY-MM-DD-ai-blockchain-digest.md)
.github/workflows # CI/CD — deploys to GitHub Pages on push to main
```

## Deployment

The site is deployed to GitHub Pages via the `deploy.yml` workflow.
To enable it on a new fork, go to **Settings → Pages** and set the source to **GitHub Actions**.

## Contributing

Drop a new post in `posts/` following the existing filename convention and push to `main`.
The deploy workflow triggers automatically.
